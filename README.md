# ✈️ Trip Budgeter

A single-page travel planner that estimates what a trip will cost and builds a day-by-day itinerary. Enter a destination, dates and a travel style, and it fills in city-specific budgets, flight and hotel estimates, and activity ideas, then tracks your estimated costs against what you actually spend.

## ✨ Features

- **City-specific estimates:** type a destination such as Paris, Tokyo, Bali, London, Dubai or Miami to load local budgets, flight costs, hotel tiers and transport prices
- **Settings that change the cost:** budget level (budget, mid-range or luxury), meal style (groceries through restaurants), transport mode (transit, rideshare, taxi or rental car) and number of travelers all recalculate the total right away
- **Seasonal and weekday pricing:** costs adjust for the time of year and the day of the week
- **Budget breakdown:** estimated versus actual cost for each category, with notes
- **Activity planner:** suggested activities filtered by culture, nature, food, shopping, adventure or nightlife, plus your own custom activities
- **Itinerary:** a day-by-day plan with a predicted cost for each day
- **Summary dashboard:** a budget health check and money-saving tips
- **Credit card points:** a toggle for using American Express points toward travel costs
- **Pre-trip checklist**
- **Saves automatically** in your browser with `localStorage`, so you don't need an account

## 🚀 How to Run

There's nothing to install or build.

```bash
git clone https://github.com/sameeksha-mehrotra/trip-planner.git
cd trip-planner
open index.html        # Windows: start index.html
```

---

## 🗂️ How to Use

1. Enter a trip name, start and end dates, and the number of travelers
2. Pick a budget level, meal style and transport mode
3. Type a destination to load city-specific data
4. Move between the **Overview**, **Budget**, **Flights & Stay**, **Activities**, **Itinerary** and **Summary** tabs
5. Fill in your actual spending as you go to see how it compares with the estimate

---

## 🛠️ Built With

Plain HTML, CSS and JavaScript in one `index.html` file. There's no framework, no backend and no external API. All the city data is built into the page.
